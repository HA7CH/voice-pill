# Contributing

Build and test with the commands in README. Keep changes small, describe the user-visible issue and list the checks you actually ran. UI previews do not prove microphone or cross-app insertion behavior.

Preserve hold-Fn Doubao, Ctrl+Fn Codex, failure recording retention, upload consent, no Return/send action, and no menu-bar item. Avoid adding paid API requirements to the default installation path.

Never commit `.signing/`, recordings, credentials, tokens, device identifiers, personal screenshots, logs or local paths. Test files should contain synthetic fixtures only. Keep upstream attribution when changing adapted code. Report issues with OS version, app name and reproducible steps; redact personal text.
